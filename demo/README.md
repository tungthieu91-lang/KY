KY Đại Kỷ Nguyên PWA V3.0

Đã chuyển Demo V2.9 thành Progressive Web App:
- Cài trên màn hình chính Android/iPhone.
- Mở chế độ toàn màn hình như ứng dụng.
- Có biểu tượng KY AI.
- Có thanh điều hướng dưới dành cho điện thoại.
- Có nút cài ứng dụng.
- Có cache cơ bản để mở nhanh và hỗ trợ một phần ngoại tuyến.
- Giữ Test AI Offline, kho bất động sản, duyệt ảnh và các tính năng demo trước đó.

Để PWA hoạt động:
- Phải đưa lên hosting HTTPS.
- Không thể cài PWA khi mở trực tiếp file C:/.../index.html.
